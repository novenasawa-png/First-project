# First-project

## Website

React site with GSAP (animation), Lenis (smooth scroll) and React Bits (text effects).

- `npm install` – get the libraries (runs on its own at the start of each Claude chat)
- `npm run dev` – run the site locally
- `npm run build` – make the finished site in `dist/`

React Bits components live in `src/components/reactbits/`. Add more by copying from https://github.com/DavidHDev/react-bits.
